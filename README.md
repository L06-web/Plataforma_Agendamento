# Projeto: Sistema de Agendamento

Este projeto é uma aplicação web simples e funcional para **agendamentos online**, com funcionalidades de **cadastro, consulta, edição, cancelamento**. É ideal para pequenas barbearias, salões de beleza ou qualquer serviço que trabalhe com horários marcados.

---

## 🚀 Funcionalidades

- 📅 **Agendamento**: permite cadastrar nome, e-mail, data, hora, tipo de serviço e observações.
- 🔎 **Consulta**: busca agendamentos salvos pelo nome do cliente.
- ✏️ **Edição**: preenche o formulário com dados existentes para serem modificados.
- ❌ **Cancelamento**: remove agendamentos do armazenamento local.
- 💬 **Chat Simulado**: interface de conversa com retorno automático fictício.

---

## 🧱 Estrutura dos Arquivos

- `index.html` - Interface principal com formulários e áreas de consulta e chat.
- `estilo.css` - Estilização visual com uma paleta única baseada em tons de azul e cinza.
- `script.js` - Lógica da aplicação, incluindo interações com `localStorage`.

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (com uso de variáveis para paleta de cores)
- JavaScript (puro, sem frameworks)
- `localStorage` do navegador (persistência de dados local)

---

## 💡 Como Usar

1. Clone ou baixe o repositório.
2. Abra o arquivo `index.html` no navegador.
3. Preencha o formulário para cadastrar um agendamento.
4. Use a seção de consulta para buscar agendamentos existentes.
5. Use os botões "Editar" ou "Cancelar" para manipular os registros.
6. Envie mensagens no chat para interações simuladas.

---

## 📂 Requisitos

Nenhum requisito especial — basta um navegador moderno. O projeto funciona **sem conexão com servidores**.

---

## 📌 Observações

- Os dados são armazenados no `localStorage`, ou seja, são **específicos para o navegador** e não persistem entre dispositivos ou sessões privadas.
- Este é um projeto front-end. Não há backend ou banco de dados real.
